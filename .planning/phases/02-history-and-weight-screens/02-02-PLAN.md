<threat_model>
ASVS L1 / block-high: no new external surface is added. Treat stored weight entries as malformed-capable, keep units/dates neutral and non-judgmental, and never log personal measurements. The material integrity risks are UTC drift in seven-day windows, duplicate dates, converting and rewriting stored mixed units, removing an old cloud document before the local edit succeeds, and updating confirmed UI on failed device storage. Use local ISO arithmetic, immutable preparation, one-entry-per-date replacement, write locally first, and only then mirror cloud operations in deterministic order.
</threat_model>
